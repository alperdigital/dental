# Dr. Dt. F. Merve BAŞ / Op. Dr. Abdulbaki BAŞ

Ana dosya `index.html`. Sayfalar, stil dosyası ve görseller göreli yollar kullanır. Derleme, API ve sunucu yapılandırması gerekmez.

## GitHub Pages

Site dosyalarını hedef deponun `main` dalındaki kök dizine ekleyin. `.nojekyll` dosyasını da dahil edin. **Settings → Pages → Build and deployment** altında **Deploy from a branch**, ardından **main / (root)** seçin.

## Yayın öncesi

- Hekim profilindeki hasta kabul adresini ve DoktorTakvimi randevu hattını klinikle teyit edin. Doğrudan klinik telefonu, çalışma saatleri ve site editörünün yayımlanabilir iletişim bilgisi sağlandığında ekleyin.
- Rehber ve tedavi metinlerini yetkili diş hekimine inceletin. İnceleyen hekimin bilgilerini ve güncelleme tarihini belirtin.
- Harita, ziyaretçi yükleme düğmesine bastığında Google’dan alınır. Randevu bağlantısı DoktorTakvimi profiline gider. Yerel form veya kişisel veri depolaması yoktur.
